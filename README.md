# PromptVerse (from Figma "Prompt-verse design")
Open `index.html` or run `python3 -m http.server` and visit http://localhost:8000.
Pages: index.html · categories.html · prompts.html?c=games|advertisements · about.html
css/styles.css · js/config.js (email + endpoint) · js/data.js (categories) · js/prompts.js (prompts from your Word file) · js/components.js (header, footer, CTA, popup, icons) · js/app.js
Add prompts: edit js/prompts.js (PV.PROMPTS.<category-slug>), put the picture in assets/images/prompts/.
Forms: Review and "more prompts" go to shahmanya152012@gmail.com through FormSubmit. The first message triggers an activation email – click its link once. Needs the site online (not file://).
